1. ALU 的设计

知识点讲解

ALU（算术逻辑单元） 是 CPU 的核心运算部件。PPT 采用自底向上的方法：先设计一位 ALU，再扩展到 32 位。

通俗理解：ALU 就像 CPU 的"计算器"，能做加、减、与、或、比较等所有运算。它是由很多个"一位计算器"组成的。

1.2 扩展 ALU 功能

实现减法

减法通过 取反加一 实现：A - B = A + (-B) = A + (~B) + 1

  • Binvert 信号（B 取反）和 1st CarryIn = 1 配合实现减法
  • PDF 第 11 页展示了扩展的一位 ALU 如何实现减法

实现 SLT（Set on Less Than）

  • 执行 rs - rt，如果结果为负 → rs < rt
  • 用结果的符号位（最高位）作为"小于"的指示器
  • 只保留最低位（Less 位），其他所有高位设为 0

  • Binvert 信号：配合减法实现；Operation 信号选择具体运算

2. 快速加法器

知识点讲解

简单的 行波进位加法器（Ripple Carry Adder） 将全加器串联，进位像波浪从低位传到高位，但速度太慢——n 位需要 2n 级门延迟。

通俗理解：行波进位就像传话游戏——第 1 个人说完传给第 2 个，依次传到最后。超前进位就像"预判"——根据已知信息提前算出每个位置的答案，不用等人传过来。

3. 整数加法和减法

知识点讲解

加法溢出检测

PDF 第 19 页给出了溢出规则：

情况 溢出条件
+ve + +ve 结果符号位 = 1（正溢出）
-ve + -ve 结果符号位 = 0（负溢出）
+ve + -ve 不会溢出

示例：7 + 6 = 13，8 位补码中 0111 + 0110 = 1101（-3），符号位变成了 1，发生溢出！

减法溢出检测

减法 = 加法取负：7 - 6 = 7 + (-6)

PDF 第 20 页：

  • 两个正数相减或两个负数相减：不会溢出
  • 负数减正数：结果符号位为 0 → 溢出
  • 正数减负数：结果符号位为 1 → 溢出

溢出处理（PPT 第 21 页）

语言/方式 指令 行为
C 语言 addu, addui, subu 忽略溢出
Ada, Fortran add, addi, sub 产生异常

异常处理流程：

  1. 保存 PC 到 EPC（Exception Program Counter）寄存器
  2. 跳转到预定义的异常处理程序
  3. mfc0 指令可读取 EPC，处理完后返回

4. 乘法运算

知识点讲解

乘法操作的核心是 移位加法。

通俗理解：二进制乘法和十进制一样——把乘数每一位与被乘数相乘（0 或 1），然后把结果移位相加。

4.1 标准乘法算法

要点：两个 n 位操作数相乘，积是 2n 位。

4.2 乘法递推公式（PPT 第 38 页）

关键特点：每次只需要相加两个 n 位数（部分积和位积），然后右移一位，不需要 2n 位加法器。

4.3 优化乘法器（PPT 第 40 页）

  • 在一个周期中并行执行 加/移位 操作
  • 乘数放在右半部分
  • 每个部分积加法需要一个周期
  • 约 32 个周期完成两个 32 位数乘法

4.4 更快的乘法器

  • 使用多个加法器并行，31 个加法器 → log₂(31) ≈ 5 个周期
  • 可以流水线化：多个乘法同时执行，每周期一个结果

4.5 MIPS 乘法指令

指令 说明
mult rs, rt 有符号乘法
multu rs, rt 无符号乘法
mfhi rd 从 HI 寄存器读取（高 32 位）
mflo rd 从 LO 寄存器读取（低 32 位）
mul rd, rs, rt 低 32 位直接存入 rd

特殊寄存器：HI/LO 是一对 32 位寄存器，存 64 位结果。

5. 除法运算

知识点讲解

除法用 试商法：

通俗理解：除法就像"试当"——每次看被除数够不够减除数，够就商 1 并减掉，不够就商 0 并挪下一位。

5.1 除法基本算法

5.2 恢复余数法（Restoring Division）

  • 先做减法，如果余数变成负数，再把除数加回去（恢复）

5.3 不恢复余数法（Non-Restoring Division）

  • 余数为正：下次减除数
  • 余数为负：下次加除数（不停在原位恢复，而是之后加回来）
  • 优点：减少了一半的加减法操作

5.4 优化除法器

  • 一个周期完成一次部分余数减法
  • 和乘法器类似，可以用同一套硬件实现
  • 更快的方法（如 SRT 除法）：通过查表一次产生多个商位，猜错后再修正

指令 说明

mfhi rd 读取余数（HI 寄存器）
mflo rd 读取商（LO 寄存器）

注意：MIPS 硬件不检查除数为 0 和溢出，需要软件自行检查。

6. 浮点数的表示（IEEE 754）

知识点讲解

浮点数用于表示非常大或非常小的实数。

通俗理解：浮点数 = 科学记数法在计算机中的应用。就像我们写 6.022×10²³，浮点数用尾数和阶码来表示所有实数。

6.1 浮点数的基本格式

机器格式：

6.2 IEEE 754 标准格式

项目 单精度（32位） 双精度（64位）
符号位 S 1 位 1 位
阶码 E 8 位 11 位
尾数 M 23 位 52 位
指数偏移 Bias 127 1023
格式 S E(8) M(23) S E(11) M(52)

6.3 规格化与隐藏位

规格化：让尾数的最高有效位恒为 1（二进制下绝对值 ≥ 1/R = 1/2）

表示法 正数 负数
原码 0.1xxxxx 1.1xxxxx
补码 0.1xxxxx 1.0xxxxx

隐藏位技术：既然规格化后最高位必定为 1，不需要显式存储，从而"偷"出额外一位精度。

6.4 浮点数的真值

单精度：x = (-1)ˢ × (1.M) × 2^(E-127)

双精度：x = (-1)ˢ × (1.M) × 2^(E-1023)

6.5 IEEE 754 特殊值的编码

符号 阶码 尾数 表示
0/1 255 ≠0 NaN（非数）
0 255 0 +∞
1 255 0 -∞
0/1 1~254 任意 规格化数：(-1)ˢ×1.f×2^(e-127)
0/1 0 ≠0 非规格化数：(-1)ˢ×0.f×2^(-126)
0/1 0 0 ±0

6.6 浮点数的表示范围

格式 最小值 最大值
单精度 1.0×2^(1-127) = 2^(-126) 1.111…1×2^(254-127) ≈ 2¹²⁷×(2-2⁻²³)

7. 浮点加减法运算

知识点讲解

浮点加减运算分为 六个步骤：

通俗理解：浮点加减法就像"对齐小数点后再加减科学记数法"。

7.1 六步运算流程

步骤 操作 说明
(1) 0 操作数检查 检查是否有 0 操作数 有 0 → 直接返回另一数
(2) 对阶 阶码小的向大的对齐 小阶尾数右移，阶码加 1
(3) 尾数加减 两尾数直接相加减 与定点数运算完全相同
(4) 结果规格化 确保尾数在正确范围 左规或右规
(5) 舍入处理 处理右移丢失的位 0舍1入 / 恒置1
(6) 溢出处理 检查阶码是否溢出 阶码上溢 → ∞；下溢 → 0

7.2 对阶原则

小阶向大阶对齐！

小阶的尾数右移，每右移一位，阶码 加1。

7.3 规格化

向左规格化（左规）：尾数最高位不是有效位 → 左移，阶码减 1

向右规格化（右规）：尾数绝对值 ≥ 1（双符号位不等：01.xxx 或 10.xxx）→ 右移，阶码加 1

补码下：

  • 正数规格化：00.1xxx…
  • 负数规格化：11.0xxx…（双符号位下符号位与最高数值位相反）

7.4 舍入方法

方法 规则
截断法 无条件丢弃移出位（最简单）
0 舍 1 入法 移出最高位=0 则舍，=1 则尾数最低位加 1
恒置 1 法 只要丢失了位，尾数最低位恒置 1

IEEE 754 提供四种可选舍入方式。

7.5 溢出判断

浮点数的溢出由阶码的溢出体现！

情况 阶码 处理
阶码上溢 阶码 > 最大正指数值 置为 +∞ 或 -∞
阶码下溢 阶码 < 最小负指数值 置为 0（机器零）

双符号位阶码判断（最高符号位固定为 0）：

  • 10 → 上溢（停止运算，中断处理）
  • 11 → 下溢（按机器零处理）
  • 01 → 结果为正，无溢出
  • 00 → 结果为负，无溢出

8. 浮点乘除法运算

知识点讲解

乘法规则

  • 阶码 = Ex + Ey
  • 尾数 = Mx × My

除法规则

  • 阶码 = Ex - Ey
  • 尾数 = Mx ÷ My

8.1 四步运算流程

步骤 操作
(1) 0 操作数检查
(2) 阶码加/减
(3) 尾数乘/除
(4) 结果规格化及舍入处理

8.2 阶码运算（移码）

移码定义：[x]移 = 2ⁿ + x（-2ⁿ ≤ x < 2ⁿ）

移码 + 补码混合运算（常用方法）：

原理：[x]移 + [y]补 = (2ⁿ + x) + (2ⁿ⁺¹ + y) = 2ⁿ⁺¹ + (2ⁿ + (x+y))
去掉最高位的 2ⁿ⁺¹ → 得 2ⁿ + (x+y) = [x+y]移

8.3 溢出判断（双符号位移码）

结果符号 含义
10 上溢
11 下溢
01 结果为正，无溢出
00 结果为负，无溢出

10. 并行性与结合律

知识点讲解

重要结论：整数加法满足结合律，但 浮点数加法不满足结合律！

10.1 反例

原因：y + z 中，z 太小（差值超过精度范围），被 y "吞没"了。

10.2 影响

  • 并行程序中操作的交错顺序可能改变浮点计算结果
  • 需要在不同程度的并行性下验证程序正确性

11. 精确算术与常见误区

知识点讲解

11.1 保护位与舍入位

在做浮点中间运算时保留额外精度位：

  • G, R：中间加法时在右侧保留的 2 个额外位
  • S：只要有过任何 1 位右移过 R 位，S 置 1

11.2 右移不等于除法！

操作 无符号数 有符号数
逻辑右移 正确除法 ✓ 错误！(-5)/4 → 00111110 = +62
算术右移 — 近似除法（(-5)/4 = -2 而非 -1）

补码负数右移不一定等于除法：-5 >> 2 = -2，但 -5/4 = -1。接近但不精确！

11.3 浮点精度的现实影响

  • Intel 奔腾 FDIV Bug（~1994）：除法查表中的一个错误值，导致 Intel 损失 3 亿多美元
  • 在 0 和 1 之间有无限多个实数，但双精度只能表示 2⁵³ 个
  • 程序员和计算机系统必须最小化"计算机算术"与"真实算术"之间的差距
