Hexo Butterfly 主题图片无法显示问题解决方案
在此之前，我在网上试过很多方法，改配置什么的，但是都没用，然后问了一下AI，最后发现是配置文件中的一行指令的原因 Hexo Butterfly 主题图片无法显示问题完全解决方案 📌 问题描述 在本地 Typora 编辑器中图片可以正常显示，但部署到 Hexo 博客后，图片无法加载，显示为空白或裂图。 🔍 原因分析 1. 本地绝对路径问题 使用了 Typora 本地缓存路径： C:\Users\用户名\AppData\Roaming\Typora\typora-user-images\xxx.png ，这类路径仅在本地电脑有效，部署到服务器后无法访问。 2. 资源路径不匹配 启用了 post_asset_folder: true 但图片没有放在与文章同名的资源文件夹中，Hexo 生成网站时不会自动复制资源到对应路径。 3. 路径格式错误 使用了错误的相对路径前缀（如 image-essay/xxx.png ），不符合 Hexo 的资源查找规则。 ✅ 完整解决方案 步骤1：确认基础配置 在站点配置文件 _config.yml 中确保配置： 1post_asset_folder...
