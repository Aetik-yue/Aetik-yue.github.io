Hexo Butterfly 主题图片无法显示问题完全解决方案

📌 问题描述

在本地 Typora 编辑器中图片可以正常显示，但部署到 Hexo 博客后，图片无法加载，显示为空白或裂图。

🔍 原因分析

1. 本地绝对路径问题

使用了 Typora 本地缓存路径： C:\Users\用户名\AppData\Roaming\Typora\typora-user-images\xxx.png ，这类路径仅在本地电脑有效，部署到服务器后无法访问。

2. 资源路径不匹配

启用了 post_asset_folder: true 但图片没有放在与文章同名的资源文件夹中，Hexo 生成网站时不会自动复制资源到对应路径。

3. 路径格式错误

  • 使用了错误的相对路径前缀（如 image-essay/xxx.png ），不符合 Hexo 的资源查找规则。

🐛 常见问题排查

  1. 大小写问题 ：Linux 服务器区分大小写，确保文件名和引用完全一致
  2. 缓存问题 ：清除浏览器缓存或使用 Ctrl + F5 强制刷新
  3. 文件存在性 ：确认图片确实已复制到对应资源文件夹
  4. 路径格式 ：不要有中文空格、特殊字符，尽量使用英文或数字命名

💡 最佳实践

  1. 新建文章时 ：Hexo 会自动创建同名资源文件夹，直接将文章用到的图片拖入即可
  2. 避免本地路径 ：写文章时直接将图片复制到资源文件夹，不要直接粘贴到 Typora 中（会生成临时路径）
  3. 批量处理 ：旧文章可以使用批量替换工具统一修改路径格式
