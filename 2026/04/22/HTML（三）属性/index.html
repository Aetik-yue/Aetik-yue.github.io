“标签怎么补充信息，怎么真正变得可用”
这就是 属性（attribute）。

可以把它理解成：

  • 标签 = 一个对象

  • 属性 = 这个对象的附加说明

例如：

这里：

  • a 是链接标签

  • href 是属性

也就是说：

标签定义“这是什么”，属性定义“它更具体是什么样、做什么、指向哪里”。

一、HTML 属性到底是什么

先看一个简单例子：

这行里：

  • img：表示图片

  • src="cat.jpg"：图片地址

  • alt="一只猫"：替代说明文字

  • width="300"：宽度

这些 src、alt、width 都是属性。

二、属性分两大类：通用属性 和 专属属性

你可以这样理解：

1）通用属性

很多标签都能用。

例如：

  • class

  • id

  • title

  • style

2）专属属性

只有某些标签常用。

例如：

  • href：主要给 a

  • src：主要给 img、script

  • alt：主要给 img

  • placeholder：主要给输入框

  • action：主要给 form

接下来我按真实开发顺序来讲。

三、最重要的通用属性

这一组非常核心，几乎每天都会用到。

1. class

这是前端里最常用的属性之一。

作用

给标签起一个“类别名”，方便：

  • 写 CSS 样式

  • 用 JavaScript 选中元素

场景 2：一个元素可以有多个 class

  • card

  • active

例如：

  • card：卡片基础样式

  • active：当前激活状态

关键理解

class 更像是：

“给元素贴标签分组”

你以后写 CSS 和 JS，会大量依赖它。

什么时候用 class

当你想：

  • 给一类元素统一样式

  • 给多个元素共享某种身份

  • 给 JS 批量操作提供选择依据

就优先考虑 class

作用

真实开发中的用法

4. style

作用

直接在标签上写样式。

真实开发中怎么看待它

能用，但通常不推荐大量使用。

因为它会让：

  • HTML 和样式混在一起

  • 样式难复用

  • 临时测试

  • 少量内联样式

  • 邮件 HTML 等特殊场景

但正常网页开发里，更推荐把样式写到 CSS 文件中，通过 class 控制。

十四、你必须建立的几个真实开发意识

1）class 和 id 不是一回事

class

给一类元素分类，可重复。

id

给一个元素唯一身份，尽量唯一。

2）placeholder 不能代替 label

placeholder 是提示，label 才是字段名称。
真实开发里，两者经常同时存在。

3）alt 不能省略

除了纯装饰图，正常图片几乎都应该认真写 alt。

4）表单提交靠 name，不是靠 id

很多新手会以为 id 最重要。
其实表单数据提交给后端时，关键通常是 name。

5）按钮的 type 最好明确写

尤其在表单里，避免默认行为带来问题。
