一、文本类标签

这类标签是网页里最基础、最常用的。

1. h1 ~ h6：标题标签

作用

表示标题层级。

真实用法

比如一篇文章页面：

关键点

  • h1 一般是页面最核心的大标题

  • h2 是章节标题

  • h3 是小节标题

  • 不要为了“字体大”就乱用标题标签

常见错误

错误想法：
“我想让字大一点，所以用 h1。”

这是不规范的。
标题标签的重点是语义，不是样式。

2. p：段落

作用

表示一段正文。

真实用法

文章、介绍、说明、正文，通常都用 p。

不要在 p 里面乱塞块级大结构。

3. br：换行

作用

强制换行。

真实用法

适合：

  • 地址

  • 诗句

  • 固定格式内容

  • 一小段里确实需要换行的文本

4. hr：分隔线

作用

表示内容主题的切换或分隔。

真实用法

它不只是“画条线”，语义上表示内容分段。

5. strong：强调，重要内容

作用

表示内容很重要。

真实用法

  • 警告

  • 重点结论

  • 特别重要的字段

和 b 的区别

  • strong：有语义，表示重要

  • b：更多是视觉加粗

开发里通常优先用 strong。

6. em：强调语气

作用

表示语义上的强调。

真实用法

  • 某个词语需要强调语气

  • 阅读时要重读的内容

和 i 的区别

  • em：语义强调

  • i：更多偏视觉上的斜体或特殊语气

一般优先理解为：
能用语义标签，就优先用语义标签。

7. span：小范围行内容器

作用

包裹一小段文字或行内内容，本身语义不强。

8. small：附属说明、小字内容

作用

表示补充说明、免责声明、次要信息。

真实用法

  • 表单提示

  • 次要说明

  • 法律免责声明

  • 版权小字

9. mark：高亮标记

作用

表示被标记或高亮的内容。

真实用法

  • 搜索关键词高亮

  • 重点片段提示

10. code：代码片段

作用

表示一小段代码。

真实用法

教程、技术文档中非常常见。

如果是一大段代码，通常会配合 pre：

11. pre：保留原始格式文本

作用

保留空格、换行、缩进。

真实用法

  • 代码展示

  • 文本排版固定内容

  • 日志片段

二、链接与资源标签

1. a：超链接

这是 HTML 里极其重要的标签。

基本写法

常见真实用法

跳转到其他网站

跳转到站内页面

跳转到页面某个位置

打电话

发邮件

常见属性

href

链接地址。

target="_blank"

新标签页打开。

title

鼠标悬停提示。

注意

如果是按钮行为，不一定非要用 a。
例如“提交表单”，那通常应该是 button。

原则：

  • 跳转页面：优先 a

  • 执行操作：优先 button

2. img：图片

基本写法

常见属性

src

图片路径

alt

替代文本，非常重要

width / height

宽高

真实用法

展示商品图

用户头像

文章配图

alt 为什么重要

很多初学者会忽略它，但它非常关键：

  1. 图片加载失败时可显示说明

  2. 对屏幕阅读器友好

  3. 对 SEO 有帮助

所以不要随手写空，除非图片纯装饰。

三、容器与布局语义标签

1. div：通用块级容器

作用

没有特殊语义，主要用来包裹一大块内容。

真实用法

  • 页面分区

  • 组件外层包裹

  • 配合 CSS 布局

  • 配合 JS 绑定逻辑

注意

div 很常用，但不要全世界只会用 div。
能用更语义化标签时，优先用语义化标签。

2. header：头部区域

作用

页面或某个区块的头部。

真实用法

  • 网站顶部

  • 文章头部

  • 卡片头部

3. nav：导航区域

作用

表示导航链接集合。

真实用法

  • 顶部导航栏

  • 侧边导航

  • 面包屑导航的一部分结构

4. main：页面主内容

作用

表示当前页面最核心的主体内容。

真实用法

一个页面通常只有一个 main。

5. section：内容区块

作用

表示主题相关的一组内容。

真实用法

  • 首页的“推荐商品”

  • “最新文章”

  • “联系我们”

  • “用户评价”

如果一个区域有自己明确的主题标题，通常很适合用 section。

6. article：独立内容单元

作用

表示一块可以独立存在、可单独分发的内容。

真实用法

  • 博客文章

  • 新闻

  • 帖子

  • 评论卡片（有时也可）

判断方法：
这块内容脱离当前页面，单独拿出去也成立吗？
如果成立，常适合用 article。

7. aside：侧边补充内容

作用

表示与主内容相关但不是核心的附加内容。

真实用法

  • 侧边栏

  • 推荐阅读

  • 广告区

  • 作者信息简介

8. footer：底部区域

作用

页面或区块底部。

真实用法

  • 网站页脚

  • 文章底部作者信息

  • 卡片底部操作信息

四、列表标签

1. ul：无序列表

作用

表示没有先后顺序的列表。

真实用法

  • 导航菜单

  • 功能特点列表

  • 标签列表

  • 商品卖点列表

2. ol：有序列表

作用

表示有顺序的列表。

真实用法

  • 操作步骤

  • 排行榜

  • 教程流程

3. li：列表项

li 必须放在 ul 或 ol 里。

五、表格标签

表格用于展示二维数据，不要拿来做页面布局。

1. table：表格

2. tr：表格行

3. th：表头单元格

4. td：普通单元格

5. thead、tbody、tfoot

让表格结构更清晰。

真实用法

  • 成绩表

  • 订单列表

  • 后台数据表

  • 财务明细

6. caption：表格标题

这对语义和可读性更好。

六、表单标签

这是非常重要的一组，真实开发里使用频率极高。

1. form：表单容器

作用

包裹用户输入区域。

真实用法

  • 登录

  • 注册

  • 搜索

  • 留言

  • 下单信息填写

2. input：输入框

最常见标签之一

type="text"：普通文本输入

真实用法

  • 用户名

  • 搜索关键词

  • 姓名

  • 标题

type="password"：密码输入

type="email"：邮箱输入

浏览器会做一些基础校验。

type="number"：数字输入

type="radio"：单选框

注意：
同一组单选框必须有相同的 name。

type="checkbox"：复选框

可多选。

type="file"：上传文件

type="submit"：提交按钮

不过现在更常见直接用 button。

3. label：表单说明标签

作用

给输入控件做说明，并增强可点击区域。

真实用法

登录表单、注册表单里几乎都该写。

为什么重要：

  • 点击文字可聚焦输入框

  • 对无障碍更友好

  • 结构更规范

4. textarea：多行文本输入

作用

输入长文本。

真实用法

  • 评论

  • 留言

  • 自我介绍

  • 地址详情

5. select 和 option：下拉框

真实用法

  • 城市选择

  • 分类选择

  • 状态选择

  • 性别选择（部分场景）

6. button：按钮

常见 type

  • submit：提交表单

  • button：普通按钮

  • reset：重置表单

真实用法

  • 登录按钮

  • 搜索按钮

  • “加入购物车”

  • “删除”

  • “确认”

十一、初学者现在最容易犯的几个问题

1）全用 div

这是最常见问题。
你能用 section、nav、header、footer 的地方，不要无脑 div。

2）把样式和结构混了

例如：
“我想红色、我想大一点，所以我要换 HTML 标签。”

不对。
HTML 管结构，CSS 管样式。

3）不会区分链接和按钮

  • 点击后去另一个页面：a

  • 点击后执行操作：button

4）忽略 label 和 alt

这两个都是新手特别容易省略、但真实开发很重要的东西。

十二、你现在该怎么练

我建议你马上做 3 个小练习：

练习 1：个人介绍页

要求：

  • h1

  • p

  • img

  • ul

  • a

练习 2：课程表页面

要求：

  • table

  • thead

  • tbody

  • tr

  • th

  • td

练习 3：注册表单

要求：

  • form

  • label

  • input

  • textarea

  • select

  • button

你只要把这 3 个页面写出来，HTML 基础会立刻稳很多。

十三、记忆方法

别按“字母表”背标签，要按“场景”记：

  • 写文章：h、p、strong、em

  • 做跳转：a

  • 放图片：img

  • 分区域：header、main、section、footer

  • 做菜单：nav + ul + li

  • 做数据：table

  • 做输入：form + input + button

这样记，最符合真实开发思路。
