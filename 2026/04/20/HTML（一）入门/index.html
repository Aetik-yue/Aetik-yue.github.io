HTML（一）入门

发表于2026-04-20|更新于2026-04-21|前端
|总字数:4.4k|阅读时长:18分钟|浏览量:

可以把 HTML 理解成：

网页的骨架。

如果把一个网页比作房子：

  • HTML 负责房子的结构：哪里是门，哪里是窗，哪里是客厅

  • CSS 负责外观：颜色、大小、布局、动画

  • JavaScript 负责行为：点击按钮后发生什么

所以前端学习里，HTML 通常是第一步。

一、HTML 到底是什么

HTML 全称是：

HyperText Markup Language
中文一般叫：超文本标记语言

这里面最重要的是“标记语言”。

它不是传统意义上“用来计算”的编程语言，而是用一些标签来告诉浏览器：

  • 这是标题

  • 这是段落

  • 这是图片

  • 这是链接

  • 这是一个列表

  • 这是一个表单输入框

浏览器看到这些标签，就会把它们渲染成网页。

五、HTML 文档的标准结构

一个完整 HTML 页面，一般长这样：

下面逐个讲。

1）<!DOCTYPE html>

这行是告诉浏览器：

这是一个 HTML5 文档。

你可以简单理解成：
“浏览器，请按现代标准来解析这个网页。”

这行通常放在第一行。

2）<html>

这是整个 HTML 文档最外层的根标签。

lang="zh-CN" 表示网页语言是简体中文。
这个属性对搜索引擎、浏览器、屏幕阅读器都有帮助。

3）<head>

head 里面放的是：

给浏览器看的信息，不是直接显示在网页正文里的内容。

比如：

  • 网页编码

  • 页面标题

  • 页面描述

  • 引入 CSS 文件

  • 引入 JS 文件的一部分配置

4）<meta charset="UTF-8">

这表示网页使用 UTF-8 编码。

你现在可以直接记住：

写中文网页时几乎总是要加这个。

否则可能出现乱码。

5）<meta name="viewport" ...>

这是为了让网页在手机上正常显示。
你现在先记结论：

现代网页一般都会写。

6）<title>

它表示网页标题，会显示在：

  • 浏览器标签页上

  • 收藏夹标题

  • 搜索结果标题的一部分

7）<body>

这里面放的是：

用户真正能在页面上看到的内容。

例如：

  • 标题

  • 段落

  • 图片

  • 链接

  • 列表

  • 表格

  • 表单

六、最常用的 HTML 标签，先学这一批

这一部分很重要。你先把最核心的掌握住。

1. 标题标签：h1 到 h6

数字越小，标题级别越高，通常也越大。

一般：

  • h1：页面主标题

  • h2：大章节标题

  • h3：小章节标题

不要因为“看起来大”就乱用标题标签。
它更重要的是表示内容层级。

2. 段落标签：p

用来放普通文字内容。

3. 换行标签：br

表示强制换行。

注意：
如果是一整段内容，优先用 <p>，不要疯狂用 <br> 代替段落。

4. 水平线：hr

显示一条分隔线。

5. 链接标签：a

点击后会跳转到对应地址。

常见属性

href

常见属性

src

图片路径

alt

替代文本，非常重要，不要省略

width / height

宽高

7. 容器标签：div 和 span

这两个非常常见。

div

块级容器，常用来分区域：

span

行内容器，常用来包裹一小段文字：

你现在先这么记：

  • div：装一大块内容

  • span：装一小段内容

它们本身没有太强语义，很多时候是为了后面配合 CSS 和 JS 使用。

七、列表

HTML 里列表很常用。

1）无序列表：ul

显示为带圆点的列表。

  • ul = unordered list

  • li = list item

2）有序列表：ol

显示为 1、2、3 这种编号列表。

八、表格

表格用来展示结构化数据。

解释：

  • table：表格

  • tr：一行

  • th：表头单元格

  • td：普通单元格

你先记住结构：

  • 表格里有很多行 tr

  • 每行里有单元格

  • 表头用 th

  • 内容用 td

九、表单

表单特别重要，因为网页经常要让用户输入内容。

比如：

  • 登录

  • 注册

  • 搜索

  • 提交留言

1）form

表示一个表单区域。

2）输入框：input

这是一个普通文本输入框。

常见类型

文本框

密码框

单选框

这里两个单选框用了相同的 name，表示它们属于同一组，只能选一个。

复选框

可多选。

3）按钮：button

4）多行文本：textarea

适合输入长文本，比如留言、简介。

5）下拉框：select

6）标签说明：label

点击“用户名”文字时，输入框也会获得焦点。
这对体验和无障碍都更好。

十、语义化标签

这是 HTML 里很重要的概念。

“语义化”就是说：

用合适的标签表达合适的内容。

不是只为了“能显示”，而是为了让浏览器、搜索引擎、开发者都知道这一块内容是什么。

比如你当然可以全用 div 写页面，但更好的方式是用更有意义的标签。

常见语义化标签

header

页头

nav

导航栏

main

页面主体

section

一个内容区块

article

独立文章内容

aside

侧边栏

footer

页脚

为什么要语义化

主要有 4 个好处：

1）结构更清晰

你自己几天后再看代码，也更容易懂。

2）更利于团队合作

别人一看就知道哪块是导航，哪块是正文。

3）更利于 SEO

搜索引擎更容易理解页面结构。

4）更利于无障碍

屏幕阅读器更容易向视障用户解释页面。

十一、块级元素和行内元素

这是初学者必须理解的一个点。

1）块级元素

特点：

  • 默认独占一行

  • 可以设置宽高

  • 常常用于布局和大块内容

常见块级元素：

  • div

  • h1 ~ h6

  • p

  • ul

  • ol

  • li

  • table

2）行内元素

  • 默认不会独占一行

  • 一般跟文字在同一行

  • 常用于包裹局部内容

常见行内元素：

  • span

  • a

  • strong

  • em

  • img（通常视为行内/行内块特点）

  • 一小段内容：常见是行内元素

十六、应该形成的核心理解

学到这里，你先抓住这几个最重要的点：

1）HTML 是网页结构

它负责告诉浏览器“这是什么内容”。

2）HTML 的核心是标签

比如：

  • h1 标题

  • p 段落

  • a 链接

  • img 图片

3）标签可以嵌套、可以带属性

属性会给标签补充信息。

4）一个标准网页有固定骨架

最重要的就是：

  • html

  • head

  • body

5）语义化很重要

尽量用有意义的标签描述内容，而不只是“能显示就行”。

十七、给你的学习顺序建议

如果你是从 0 开始，HTML 可以按这个顺序学：

第 1 阶段：先会写简单页面

学这些标签：

  • html

  • head

  • title

  • body

  • h1 ~ h6

  • p

  • a

  • img

  • div

  • span

第 2 阶段：会组织内容

学这些：

  • ul

  • ol

  • li

  • table

  • form

  • input

  • button

  • textarea

  • select

第 3 阶段：理解规范写法

学这些：

  • 语义化标签

  • 合理嵌套

  • 属性

  • 注释

  • 基本页面结构

第 4 阶段：开始衔接 CSS

这时候你再去学：

  • 选择器

  • 颜色

  • 字体

  • 盒模型

  • 布局

十九、总结

HTML 就是用标签来定义网页内容结构的语言。

它不负责“漂亮”，也不负责“交互逻辑”，它先负责把网页的骨架搭起来。
